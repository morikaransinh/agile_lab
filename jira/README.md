# Jira Scrum backlog

The CSV in this folder contains three import-ready user stories for project
**AL**. It was prepared for the Jira project URL supplied by the project owner.

## Import the stories

1. Sign in to Jira and open project **AL**.
2. Use Jira's CSV issue import (typically under **Settings → System → External
   System Import → CSV**; your Jira permissions may change the menu location).
3. Upload `user_stories.csv` and map `Issue Type`, `Summary`, `Description`,
   `Priority`, and `Labels`.
4. Map `Story Points` to the project's Story Points field. If that field is not
   available, ask a Jira administrator to add the numeric field to the project.
5. Review the import preview, then create the issues.

## Scrum workflow demonstration

Create a sprint in the AL Scrum board, add the three stories to the backlog, and
order them by priority. Start the sprint, move a story through **To Do → In
Progress → Done**, and show the sprint board and backlog. The exact transition
labels depend on the workflow configured in Jira.
